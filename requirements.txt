# =============================================================================
# MarketMind Sim — core runtime dependencies
# =============================================================================
# Everything required to launch the web interface, replay the included sample
# results, and run Rule / LLM / RuleLLM simulations.  Tested on Python 3.11.
#
# Installation (see README.md for the full walkthrough):
#
#     python -m venv .venv
#     # Windows: .venv\Scripts\activate    |   macOS/Linux: source .venv/bin/activate
#     pip install -r requirements.txt
#     pip install -e . --no-deps
#
# NOTES
# -----
# * ``lmbase`` is bundled IN this repository (``./lmbase``) as a small offline
#   stub providing the interfaces masim imports lazily (InferInput /
#   InferOutput / LangChainAPIInference / BlockBasedStoreManager).  It is
#   installed automatically from the local folder by the ``-e ./lmbase``
#   line below — no network clone or API key is required.
# * The RAG engine variants (examples/*/Rag) need extra, heavier dependencies
#   (llama-index, PyMuPDF, a local embedding model).  They are OPTIONAL and
#   kept in ``requirements-rag.txt``:
#
#       pip install -r requirements-rag.txt
#
# * LLM / RuleLLM variants call an external model API; set ARK_API_KEY (or
#   the provider's key) in a ``.env`` file.  Rule variants and the whole
#   interface work fully offline with no API key.
# =============================================================================
